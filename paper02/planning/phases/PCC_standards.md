## 2. Exhaustive Tasks & Subtasks

### Task CC.1: Deep Codification of the 7 Rule Groups
1. **Group CC.1 — Reproducibility & Runtime Provenance:**
   - *CC.1.1 (Metadata Logging):* Every run must log Python, PyTorch, JAX, Diffrax versions, CUDA driver, GPU model, Git commit hash, and timestamp.
   - *CC.1.2 (Deterministic Seeding):* Random seeds must be explicitly generated as `seed = run_id * 42 + 7`. Deterministic PyTorch flags (`deterministic=True`, `benchmark=False`) must be asserted in all harnesses.
   - *CC.1.3 (Scripted Reproduction):* No numerical result is acceptable unless reproducible by executing a single script from `paper02/src/` with a CLI command.
2. **Group CC.2 — Numerical Integrity & Solvers:**
   - *CC.2.1 (ODE Tolerance Floors):* Continuous gradient flow solvers (Diffrax) must enforce absolute tolerance $\le 10^{-8}$ and relative tolerance $\le 10^{-8}$.
   - *CC.2.2 (Kernel Unit Testing):* Every custom mathematical kernel, gradient projection, or CKA metric function must have $\ge 3$ unit tests covering edge cases (zero inputs, orthogonal vectors, collinear vectors).
   - *CC.2.3 (Equivalence Testing Protocol):* Parity claims must be pre-registered and evaluated using Two-One-Sided Tests (TOST) within a default $\pm 2.5\%$ margin.
3. **Group CC.3 — Writing & Epistemic Discipline:**
   - *CC.3.1 (Abstract Bound):* Abstract must be $\le 250$ words and state the claim status explicitly.
   - *CC.3.2 (Figure Standards):* All figures must be vector format (TikZ/PGFPlots) or 300+ DPI PNG, with labeled axes, explicit units, data provenance, and 95% bootstrap confidence bands.
   - *CC.3.3 (Tripartite Separation):* Clear separation between: (i) Mathematical theorems proven in the model, (ii) Empirical findings in neural networks, and (iii) Open conjectures.
4. **Group CC.4 — Data Hygiene & Immutability:**
   - *CC.4.1 (Raw Tensor Immutability):* All raw tensors in `data/raw/` are write-once and immutable. Processed tables in `data/processed/` must be generated by idempotent scripts.
   - *CC.4.2 (Zero-Leakage Support Disjointness):* Zero-shot compositional test sets must be mathematically proven to have zero support overlap with in-distribution training sets.
5. **Group CC.5 — Release Readiness & Open Science:**
   - *CC.5.1 (Self-Contained Repo):* The codebase must run cleanly from a fresh clone without private external dependencies.
   - *CC.5.2 (Double-Blind Compliance):* Anonymized source trees must strip author names, institution references, and personal URLs.
6. **Group CC.6 — Agentic Protocol & Git Conventions:**
   - *CC.6.1 (Conventional Commits):* Commits must use `[Tag][Scope][Δ] Description`.
   - *CC.6.2 (Artifact Immutability):* No prior artifact may be overwritten without a superseding ADR.
7. **Group CC.7 — Ethics & Broader Impact:**
   - *CC.7.1 (Impact Statement):* A dedicated section must analyze the broader impact of automated schema induction.
