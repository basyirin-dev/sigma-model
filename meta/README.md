# Σ-Model: Research Planning Framework (RPF) v2.0 Workspace

This repository houses the end-to-end theoretical, computational, and empirical research programme for the **Σ-Model** dynamical-systems framework for compositional generalisation failure.

## Repository Overview

- **`planning/`**: Living roadmap, claim ledger, risk register, compute budget, and phase definitions (P00–P14).
- **`decisions/`**: Architecture Decision Records (ADRs) and human-gate directive logs.
- **`src/`**: Modular Python and Julia computational kernels (`simulation/`, `analysis/`, `utils/`).
- **`configs/`**: Experiment and environment configurations.
- **`data/`**: Data directories (`raw/`, `processed/`, `synthetic/`).
- **`experiments/`**: Run logs, manifests, serialized agent state, and negative/divergent results.
- **`literature/`**: Systematic screening log, knowledge graph, PDFs, and BibTeX bibliography.
- **`writing/`**: Quarto manuscripts, figures, and supplementary materials.
- **`scripts/`**: Automation tools, compliance linters, and phase exit verification engines.
- **`tests/`**: Unit, integration, and clean-room reproducibility test suites.
- **`meta/`**: Operating manuals, seed registries, environment specifications, and bootstrap guides.
- **`.pi/`**: Local Pi agent extensions, skills, tools, and composable prompt snippets.
