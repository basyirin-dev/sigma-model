## Steps

### 1. Create OSF Project
- Go to https://osf.io and log in
- Click **Create new project**
- **Title:** `Schema Coherence and the σ-Trap — A Systematic Review`
- **Description:**
  ```
  Systematic review and meta-analysis protocol investigating the σ-trap (schema-coherence trap) in neural network compositional generalisation. Searches Scopus, WoS, ACM DL, IEEE Xplore, arXiv, PsycINFO. PRISMA-P 2015 compliant protocol.
  ```
- **License:** CC-By Attribution 4.0 International
- Click **Create**

### 2. Upload Protocol
- Inside the project, click **Files** → **OSF Storage** → **Upload**
- Select `manuscript/protocol.pdf`

### 3. Add Metadata
- **Tags:** `systematic review, meta-analysis, schema coherence, compositional generalization, sigma-trap, PRISMA-P`
- **Category:** Project
- Under **Contributors**, ensure your name is listed

### 4. Register the Protocol (Immutable Snapshot)
- Click the **Registrations** tab
- Click **New Registration**
- Select **Open-Ended Registration** (or **Preregistration** if available)
- Confirm the PDF is the correct version
- Complete the registration
- This creates a date-stamped, immutable registration linked to the project
