# Phase 9 — Thematic Synthesis

**Duration**: 3 weeks (Month 4–5)
**Deadline**: 2026-11-05
**Dependencies**: Phase 7 (charted data), Phase 8 (quality scores)
**Output**: Thematic synthesis narrative; structured results for scoping review manuscript

---

### Task 9.1: Descriptive Numerical Summary

- [ ] 9.1.1: Generate basic descriptive statistics:
  - Total number of papers included
  - Year distribution (2015–2026, with annual counts)
  - Publication venue distribution
  - Publication type distribution
  - Geographic/institutional distribution
- [ ] 9.1.2: Generate subdomain frequency analysis:
  - Which subdomains of AGI safety are most/least represented?
  - How has subdomain focus changed over time?
  - Co-occurrence of subdomains (which tend to appear together?)
- [ ] 9.1.3: Generate methodology frequency analysis:
  - Which methodologies are most/least used?
  - How does methodology vary by subdomain?
  - Formal methods vs. conceptual analysis breakdown
- [ ] 9.1.4: Create figures: bar charts, time series, co-occurrence matrix, geographic map
- [ ] 9.1.5: Export all figures as publication-ready PDF/SVG

### Task 9.2: Thematic Analysis

- [ ] 9.2.1: Review charted data for recurring themes across all papers
- [ ] 9.2.2: Use open coding: extract themes from paper contributions and findings
- [ ] 9.2.3: Group open codes into axial themes: what subdomain clusters emerge?
- [ ] 9.2.4: Cross-reference themes with quality scores — are high-credibility papers concentrated in specific themes?
- [ ] 9.2.5: Identify cross-cutting themes (themes that appear across multiple subdomains)
- [ ] 9.2.6: Map themes to the overarching thesis (schema coherence, σ-trap, compositional generalization–alignment connection)
- [ ] 9.2.7: Document the theme development process in `research/thematic-synthesis.md`

### Task 9.3: Gap Analysis

- [ ] 9.3.1: From the extracted data and thematic synthesis, identify gaps:
  - Subdomains with minimal coverage
  - Methodological gaps (lack of formal methods, lack of empirical work)
  - Theoretical gaps (missing connections between subdomains)
  - Temporal gaps (declining/emerging areas)
- [ ] 9.3.2: Cross-reference gaps with Phase 0.5 `research/gap-analysis.md` — which were confirmed, refuted, or newly discovered?
- [ ] 9.3.3: Prioritize gaps by relevance to the overarching thesis
- [ ] 9.3.4: Document how each gap feeds into Papers 02, 03, and 09

### Task 9.4: Structured Results Section

- [ ] 9.4.1: Draft the Results section structure:
  - Descriptive overview (numerical summary)
  - Results by subdomain (value alignment, interpretability, robustness, mesa-optimization, governance, etc.)
  - Cross-cutting themes
  - Gaps identified
- [ ] 9.4.2: For each subdomain section:
  - Characterize the literature volume, growth trajectory, and key venues
  - Identify the dominant methodological approaches
  - Summarize key findings and debates
  - Note quality/credibility assessment
- [ ] 9.4.3: For cross-cutting themes section:
  - Identify themes that span multiple subdomains
  - Discuss their implications for AGI safety as a whole
  - Map to the overarching thesis
- [ ] 9.4.4: For gaps section:
  - Detail each gap with supporting evidence from the charted data
  - Explain implications for the field and for subsequent thesis papers
- [ ] 9.4.5: Satisfy CC.3.2 — thesis coherence: gaps mapped to Papers 02–09

### Task 9.5: Results Verification
