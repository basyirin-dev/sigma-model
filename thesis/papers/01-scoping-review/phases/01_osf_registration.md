# OSF Registration Instructions — Paper 01 Protocol

## Prerequisites
1. OSF account at https://osf.io
2. Protocol PDF ready: `01_protocol_draft.pdf` (generated)

## Steps

### 1. Create OSF Project
- Go to https://osf.io and log in
- Click **Create new project**
- Title: `Landscape of AGI Safety — A Scoping Review`
- Description: (paste from `01_protocol_draft.md` §2 Abstract)
- License: CC-By Attribution 4.0 International (recommended for protocols)
- Click **Create**

### 2. Upload Protocol
- Inside the project, click **Files** → **OSF Storage** → **Upload**
- Select `phases/01_protocol_draft.pdf`

### 3. Add Metadata
- Click **Add tags**: `AGI safety, scoping review, PRISMA-ScR, AI alignment, schema coherence`
- Set **Category**: Project → **Registration** → **Scoping Review Protocol** (or closest match)
- Under **Contributors**, ensure your name is listed

### 4. Register the Protocol
- Click the **Registrations** tab
- Click **New Registration**
- Select **Preregistration** as the registration template (or **Open-Ended Registration**)
- Confirm the PDF is the correct version
- Complete the registration
- This creates a date-stamped, immutable registration linked to the project

### 5. Record the Link
- Copy the registration URL (format: `https://osf.io/xxxxx`)
- Update `phases/01_protocol.md` Task 1.5.4 with the link
- Update `README.md` with the OSF link in the Protocol section

### 6. Verify
- Confirm the registration is publicly viewable
- Check that the PDF renders correctly in the browser viewer
- The registration timestamp serves as evidence of pre-screening protocol commitment (CC.1.7, CC.1.3)

## Troubleshooting
- **Registration types**: If "Preregistration" template is not available, use "Open-Ended Registration"
- **PDF preview**: OSF may take a moment to generate thumbnails
- **Private vs public**: Register as public for maximum transparency per PRISMA-ScR
