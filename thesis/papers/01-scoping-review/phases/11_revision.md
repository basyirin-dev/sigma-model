# Phase 11 — Revision & Polishing

**Duration**: 3 weeks (Month 5–6)
**Deadline**: 2026-12-17
**Dependencies**: Phase 10 (first draft complete)
**Output**: Revised, polished manuscript ready for internal review

---

### Task 11.1: Self-Review

- [ ] 11.1.1: Read entire draft aloud — catch awkward phrasing, run-on sentences, missing transitions
- [ ] 11.1.2: Check logical flow: does each section build on the previous one?
- [ ] 11.1.3: Verify that all claims in Results are supported by the charted data
- [ ] 11.1.4: Verify that Discussion accurately reflects Results (no overclaiming or underclaiming)
- [ ] 11.1.5: Check all figure captions: are they self-contained and informative?
- [ ] 11.1.6: Satisfy CC.2.2 — consistent formatting

### Task 11.2: Structural Revision

- [ ] 11.2.1: Ensure each section has a clear topic sentence and logical paragraph structure
- [ ] 11.2.2: Ensure Methods section is replicable (could someone re-run the search?)
- [ ] 11.2.3: Ensure Results section is comprehensive (all PRISMA-ScR items addressed)
- [ ] 11.2.4: Ensure Discussion section acknowledges all limitations identified in Phase 9
- [ ] 11.2.5: Add signposting: "as discussed in Methods", "as shown in Figure 3"
- [ ] 11.2.6: Satisfy CC.1.1 — PRISMA-ScR checklist items verified

### Task 11.3: Writing Quality Pass

- [ ] 11.3.1: Eliminate jargon where plain language suffices
- [ ] 11.3.2: Shorten sentences (target: <25 words average)
- [ ] 11.3.3: Eliminate passive voice where active is clearer
- [ ] 11.3.4: Ensure consistent tense (present for established facts, past for methods/results)
- [ ] 11.3.5: Run language check (Grammarly, LanguageTool, or similar) and address findings

### Task 11.4: Figure and Table Refinement

- [ ] 11.4.1: Check all figures for resolution, readability, and color accessibility (colorblind-safe)
- [ ] 11.4.2: Standardize figure style (fonts, line weights, color scheme) across all figures
- [ ] 11.4.3: Ensure all tables are well-formatted in LaTeX
- [ ] 11.4.4: Check that all figures/tables are cited in the text in order
- [ ] 11.4.5: Satisfy CC.6.4 — figures at correct DPI

### Task 11.5: Reference Verification

- [ ] 11.5.1: Verify every in-text citation has a corresponding bibliography entry
- [ ] 11.5.2: Verify every bibliography entry is cited in the text
- [ ] 11.5.3: Check DOIs for all entries (where available)
- [ ] 11.5.4: Check that reference formatting matches venue guidelines
- [ ] 11.5.5: Satisfy CC.6.3 — references formatted per venue style

### Task 11.6: Internal Review

- [ ] 11.6.1: Send draft to 1-2 colleagues for feedback
- [ ] 11.6.2: Provide reviewers with specific questions (e.g., "Is the scope too broad?", "Are any key papers missing?")
- [ ] 11.6.3: Collect and collate feedback
- [ ] 11.6.4: Address all substantive feedback (categorize: accept, reject with rationale, partially accept)
- [ ] 11.6.5: Thank reviewers in acknowledgments

### Task 11.7: Second Draft

- [ ] 11.7.1: Incorporate all accepted reviewer feedback
- [ ] 11.7.2: Re-read the revised manuscript end-to-end
- [ ] 11.7.3: Make final language and formatting pass
- [ ] 11.7.4: Satisfy CC.6.1 — manuscript compiles without errors

---

**Phase 11 Exit Criteria**:
- [ ] Self-review complete
- [ ] Structural revision complete
- [ ] Writing quality pass complete
- [ ] Figures and tables refined
- [ ] References verified and formatted
- [ ] Internal review completed and feedback addressed
- [ ] Second draft ready for submission prep
- [ ] CC.1.1, CC.2.2, CC.6.1, CC.6.3, CC.6.4 satisfied
- [ ] CC.5.3 satisfied — phase completion committed
