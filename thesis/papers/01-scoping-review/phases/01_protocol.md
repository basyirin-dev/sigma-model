# Phase 1 — Research Question & Protocol

**Duration**: 1 week (Month 1–2)
**Deadline**: 2026-07-30
**Dependencies**: Phase 0.5 (research artifacts completed)
**Output**: Registered protocol on OSF with finalized research question, objectives, and inclusion/exclusion criteria

---

### Task 1.1: Finalize Research Question

- [ ] 1.1.1: Review Phase 0.5 research outputs — especially `research/landscape-boundary.md` and `research/gap-analysis.md`
- [ ] 1.1.2: Refine the overarching research question using PCC (Population, Concept, Context) framework:
  - Population: AI/AGI research community
  - Concept: AGI safety frameworks, approaches, and failure modes
  - Context: Peer-reviewed and grey literature 2015–2026
- [ ] 1.1.3: Define 3-5 sub-questions (e.g., "What subdomains constitute AGI safety?", "What formal methods are used?", "How does internal representation structure feature in safety discussions?")
- [ ] 1.1.4: Draft explicit objectives using SMART framework
- [ ] 1.1.5: Satisfy CC.1.4 — inclusion/exclusion criteria drafted concurrently with question

### Task 1.2: Define Inclusion/Exclusion Criteria

- [ ] 1.2.1: Inclusion criteria:
  - Written in English
  - Published 2015–2026 (with justification: AlphaGo/DeepMind safety defined field in ~2015)
  - Addresses at least one AGI safety subdomain explicitly
  - Peer-reviewed article, arXiv preprint, technical report, or well-known blog post
- [ ] 1.2.2: Exclusion criteria:
  - Narrow AI safety only (e.g., autonomous vehicle safety without AGI relevance)
  - Not in English
  - Opinion pieces without substantive technical/scholarly content
  - Duplicate or overlapping publications (same content in multiple venues — keep the most complete)
- [ ] 1.2.3: Justify each criterion with reference to Phase 0.5 findings (especially `research/existing-reviews.md`)
- [ ] 1.2.4: Satisfy CC.1.4 — criteria explicitly stated before screening

### Task 1.3: Write Protocol

- [ ] 1.3.1: Draft protocol following PRISMA-ScR guidelines:
  - Title and abstract
  - Introduction / rationale
  - Research question(s) and objectives
  - Eligibility criteria (inclusion/exclusion)
  - Search strategy (databases, date limits, language limits — details deferred to Phase 2)
  - Study selection process (screening protocol, expected dual-screening)
  - Data charting process (extraction method)
  - Synthesis approach
- [ ] 1.3.2: Decide on staged approach (whether to search all databases simultaneously or iteratively)
- [ ] 1.3.3: Protocol length: ~5-10 pages
- [ ] 1.3.4: Satisfy CC.1.7 — register protocol on OSF (or similar open repository)

### Task 1.4: Pilot Search Test

- [ ] 1.4.1: Choose one representative database (e.g., Scopus or arXiv)
- [ ] 1.4.2: Execute preliminary search with draft terms from Phase 0.5 `research/search-terms.md`
- [ ] 1.4.3: Review 20-30 random results to verify sensitivity/specificity balance
- [ ] 1.4.4: Adjust inclusion/exclusion criteria if pilot reveals missing or irrelevant results
- [ ] 1.4.5: Record pilot search details (database, date, string, yield, adjustments made)
- [ ] 1.4.6: Satisfy CC.1.5 — data charting form developed and piloted

### Task 1.5: Protocol Registration

- [ ] 1.5.1: Create OSF project for Paper 01
- [ ] 1.5.2: Upload protocol document
- [ ] 1.5.3: Make protocol publicly viewable
- [ ] 1.5.4: Record OSF link in `README.md`
- [ ] 1.5.5: Satisfy CC.1.3 — protocol registered prior to formal search
