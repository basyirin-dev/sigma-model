# Chapter 5: σ-Coupling Interventions — Pilot Study

**Source**: Paper 04 — *σ-Coupling Interventions* (Pilot Study)
**Status**: ⚪ Not started — wait for Ch 4
**Timeline**: Months 13–18
**Role**: Tests the causal chain **intervention → σ↑ → CG↑** (external assessment F5). The pilot
must test all three links, not merely "intervention → performance↑" (which does not demonstrate
the σ mechanism).

## Design Requirements (required)

- **Conditions**: Control vs σ-coupling intervention (pre-registered; power analysis / sample-size justification).
- **Measurements** (in both arms): σ (per the Ch 4 operational definition); compositional generalisation (OOD); ordinary in-distribution performance; robustness; training dynamics.
- **Analysis**: mediation (intervention → σ → CG). If σ rises but CG does not change, the framework requires revision — that is a publishable, falsifying result (see falsifiability criterion).
- **Sensitivity**: LLM-assisted analysis components report independent human adjudication samples (CC.3.7); robustness to alternative explanations section (CC.4.8).
