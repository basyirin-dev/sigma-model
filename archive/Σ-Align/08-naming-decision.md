# 8. Naming Decision

## 8.1 Problem

The new research direction needed a name that:
1. Signals continuity with the Σ-Model formalism (schema coherence $\sigma$)
2. Communicates the new focus (alignment)
3. Allows future extensibility
4. Is distinct from existing project names

## 8.2 Candidates Evaluated

### Greek Letter Convention (Continuing the Σ-Model lineage)

| Name | Symbol | Meaning | Pros | Cons |
|:-----|:-------|:--------|:-----|:-----|
| **Σ-Align** | Sigma-Align | $\sigma$ (schema coherence) + Alignment | Direct lineage; $\sigma$ already defined in paper; extensible (Σ-Interpret, Σ-Certify) | Carries protein-domain history |
| **Γ-Model** | Gamma-Model | $\Gamma$ for General intelligence or Goal preservation | Clean break; fresh identity | Must define $\Gamma$ from scratch; sequel paper would need to introduce new notation |
| **Φ-Align** | Phi-Align | $\Phi$ for Foundational or Formal alignment | Emphasizes provability | $\phi$ is already used in Σ-Model for Domain similarity coupling ($\phi(d_1, d_2)$) |
| **Ω-Align** | Omega-Align | $\Omega$ as ultimate/terminal destination | Bold claim | $\Omega_{SL}$ is already used in Σ-Model for Shortcut learning pressure |

### Descriptive Names (Rejected)

| Name | Reason for Rejection |
|:-----|:--------------------|
| The Coherence Thesis | Too generic, doesn't signal alignment |
| Schema Alignment Framework | Cumbersome, not memorable |
| $\sigma$-Trap Theory | Focuses on problem rather than solution |

## 8.3 Decision: Σ-Align

**Selected:** Σ-Align

### Rationale

1. **Preserves the $\sigma$ formalism.** Schema coherence ($\sigma_A$) is the core mathematical quantity in the Σ-Model. The symbol carries meaning across papers without redefinition.

2. **Signals the new direction.** "Align" immediately communicates the focus on AI safety and alignment, distinguishing it from the original protein-domain application.

3. **Allows future family expansion.** Σ-Align can be extended without namespace exhaustion:
   - Σ-Interpret (mechanistic interpretability)
   - Σ-Certify (formal verification + certification)
   - Σ-Proof (theorem-proving for alignment)
   - Σ-Core (foundational agent theory)

4. **Publication-linear.** The intellectual thread writes itself:
   - Paper 1: Σ-Model (published, under review)
   - Paper 2: Σ-Align (sequel, ODE → mesa-optimization)
   - Paper 3: Σ-Proof (formal results, theorems)

### Pronunciation

"Sigma-Align" — explicitly stating both components.

### Symbol

$\Sigma$-Align (LaTeX: `\Sigma\text{-Align}`)

## 8.4 Relationship to Σ-Model

Σ-Align is a **fork** of the Σ-Model project — it inherits the mathematical formalism while redirecting the application domain. The Σ-Model repository remains as the canonical record of Paper 1. Σ-Align starts as a new repository with explicit provenance documentation.
