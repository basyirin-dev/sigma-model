## 3. Data Directory Structure

Files are stored at `data/pfam/`:

```
data/pfam/
├── raw/                        # Original Pfam distribution files
│   ├── Pfam-A.hmm              # HMM profiles (HMMER3 binary, ~2.1 GB) [extracted]
│   ├── Pfam-A.seed             # Seed alignment (Stockholm, ~602 MB) [extracted]
│   ├── Pfam-A.hmm.dat          # HMM metadata (~4.7 MB) [extracted]
│   ├── Pfam-A.clans.tsv        # Clan mapping (~1.8 MB) [extracted]
│   ├── Pfam-A.hmm.gz           # Compressed originals (kept)
│   ├── Pfam-A.seed.gz
│   ├── Pfam-A.hmm.dat.gz
│   ├── Pfam-A.clans.tsv.gz
│   ├── Pfam.version.gz
│   ├── relnotes.txt
│   ├── md5_checksums           # EBI-published MD5 checksums
│   └── SHA256SUMS              # Local SHA256 checksums
├── processed/                  # Derived artifacts (generated by scripts/verify_pfam_pipeline.py)
│   ├── architectures.pt         # Tokenised architecture tensor (n x max_len, int64)
│   ├── architectures.json       # Raw architecture sequences (list[list[str]])
│   ├── vocab.json               # token2id + id2token mappings
│   ├── clan_map.json            # Pfam base accession → clan ID
│   ├── splits.pt                # Split indices for Type A/B/C, each with ID/OOD
│   ├── split_stats.json         # Per-split statistics
│   └── similarity_matrix.npy   # K×K float32 (precomputed via precompute_similarity_matrix)
└── metadata/                   # Supplementary annotations
    ├── clan_info.json           # Pfam clan membership
    ├── family_taxonomy.json     # Family → fold classification
    └── README.md                # Notes on download process
```

## 6. Verification steps

```bash
# Step 1: Verify archive integrity (SHA256)
sha256sum -c data/pfam/raw/SHA256SUMS

# Step 2: Verify against EBI-published MD5
md5sum -c data/pfam/raw/md5_checksums

# Step 3: Validate HMMER3 format
gunzip -c data/pfam/raw/Pfam-A.hmm.gz | hmmstat - 2>&1 | head -5

# Step 4: Check pyhmmer compatibility
python -c "
import pyhmmer
with pyhmmer.plan7.HMMFile('data/pfam/raw/Pfam-A.hmm') as f:
    hmm = next(f)
    print(f'First HMM: {hmm.name} ({hmm.accession})')
"
```

## 7. Data Provenance Notes

- **Pfam release cycle:** approximately March and September each year.
- **Version pinning:** pin to a specific release for reproducibility; do not float on `current_release`.
- **Distance metric:** `hmm_bit_score` (configured in `pfam-base.yaml`) is computed via HMMER3 domain–domain bit score comparison, available through `pyhmmer`.
- **ESM embeddings** (Phase 6 validation): cached separately at `experiments/output/esm_embeddings/`, already gitignored by the existing `experiments/output/` rule.
- **License:** Pfam data is freely available under the CC0 1.0 Universal Public Domain Dedication.

## 8. Processed Cache (`data/pfam/processed/`)

Generated by `scripts/verify_pfam_pipeline.py --full --cache`.

| Artifact | Format | Contents |
|----------|--------|----------|
| `architectures.pt` | PyTorch tensor | `(n_archs, max_len)` int64, padded with `<PAD>` |
| `architectures.json` | JSON | Raw architecture accessions (debugging) |
| `vocab.json` | JSON | `token2id` + `id2token` mappings |
| `clan_map.json` | JSON | Base accession → clan ID |
| `splits.pt` | PyTorch dict | `{type_a: {id: [indices], ood: [indices]}, ...}` |
| `split_stats.json` | JSON | Per-split statistics from `compute_split_statistics` |
| `similarity_matrix.npy` | NumPy | N×N float32 (optional; precomputed separately) |

**Regeneration:**
```bash
PYTHONPATH=code:$PYTHONPATH python scripts/verify_pfam_pipeline.py --full --cache
```

The similarity matrix is **not** generated by the pipeline (18h CPU). Precompute separately via `precompute_similarity_matrix()` and pass `--sim-matrix PATH`.
