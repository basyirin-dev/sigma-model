## Analyses (required)

- Primary pooled estimate **within each family** (random-effects; heterogeneity I² reported).
- Subgroup analyses.
- **Leave-one-construct-out** sensitivity.
- **High-quality-only** sensitivity (e.g. tiers A+B from the Ch 3 evidence table).
- Publication-bias assessment (PRISMA-MA).
- Every effect must be traceable to the Ch 3 evidence table (study, construct, operationalisation, design, N, effect, variance, quality).

## Interpretation Guardrail

If construct heterogeneity within a family is intractable (e.g. I² > 90% with no coherent
subgroup), report a narrative synthesis of mechanistic parallels instead of a pooled number —
per the external-assessment recommendation.
